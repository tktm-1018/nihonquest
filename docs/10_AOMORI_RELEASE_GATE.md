# 青森 MVP Go / No-Go 判定書

判定日: 2026-10-03

対象: `codex/quality-release-gate`

判定: **No-Go**

## 判定理由

- 青森 P0 静的素材19件はリポジトリ内の手続き型アートから決定論的に書き出し、未配置0件。権利証跡は `content/quality/media-rights.json` に記録した。
- 高優先教材30件は判断記録済みだが、dated-fact 12件も visual-context 18件も学術責任者の承認前。特に visual-context 18件は参照図版との対応が確認できず、未承認を維持する。
- 本番問題44ファイルは構造検証済みだが、学術レビューは全件 `pending-human-academic-review`。承認状況は `content/quality/release-reviews.json` を正とする。
- BGM・SE・英語音声の同梱ファイルは0件。権利不明素材はないが、音素材を追加するときは `content/quality/media-rights.json` に証跡を追加してから同梱する。

## 機械検証

`pnpm check` は lint、構造、unit、content、教材・権利台帳、型、build を連続実行する。CI はこれらに Chromium E2E を加える。unit の下限は 519 件で、基準実行は 525 件成功。

性能予算は初回ロード 5,000 ms、メニュー初回表示 1,000 ms、デバッグ戦闘開始 5,000 ms とする。計測は `tests/e2e/release-quality.spec.ts` で行い、計測値なしで遅延読み込みを追加しない。

## Go への残条件

1. 高優先30件を氏名付きレビューで再審査し、図版18件は原票まで照合する。
2. 44問題ファイルの学術レビューを完了する。

条件未達のため、公開・教材承認は行わない。

## 2026-10-03 実測結果

- `pnpm check`: 成功（unit 525、content validation error 0、lint・構造・型・build成功）。
- Chromium E2E: 17件すべて成功。タイトル→青森→県ボス→しるし保存→続行、対戦場報酬保存、通常戦闘、タッチ、ルビ、保護者画面を含む。
- 性能予算: 初回ロード5,000 ms未満、メニュー初回表示1,000 ms未満、戦闘開始5,000 ms未満の全項目に合格。計測後、タイトルで不要だった素材の先行生成を停止し、問題一覧DOMを初回500行に制限した。戦闘ロジックは変更していない。
- 全601素材の分類: 青森MVP 19件（配置済み）、東北67件（未配置）、全国515件（未配置）。青森P0不足は0件。
- dated-fact 12件: 一次資料を8件に紐付け、一次資料を特定できない4件は未承認のまま。visual-context 18件は原票照合前のため全件未承認。
- 高優先30件: 全件に判断記録あり、未確認項目を承認していない。
- 本番44問題ファイル: 構造検証済み、学術承認0件、44件すべて `pending-human-academic-review`。
- BGM・SE同梱0件、英語音声はWeb Speech APIによる実行時音声のみ。ライセンス不明素材の追加なし。
