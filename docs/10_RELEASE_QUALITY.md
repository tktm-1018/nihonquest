## 自動検査

```bash
pnpm lint
pnpm check:architecture
pnpm test
pnpm validate:content
pnpm audit:curriculum
pnpm audit:assets
pnpm build
pnpm test:e2e
```

`pnpm audit:assets` は `imports/asset-backlog.json` を決定的に再生成します。同じファイル構成から実行した場合、時刻だけで差分が発生してはいけません。

## 人間の確認が必要なゲート

1. 問題ファイルを一次資料と照合し、確認者・確認日・出典・SHA-256 を `content/quality/academic-reviews.json` に記録する。
2. 更新情報候補と画像・表の文脈確認候補に、修正・現状維持・保留の判断を付ける。
3. 公開素材ごとに作者、入手元、利用条件、改変可否、クレジット要否を確認する。
4. 小学生によるタッチ操作だけの通しプレイと、保護者による設定・セーブ入出力を確認する。

## MVP の公開を止める条件

- `docs/00_GAME_DESIGN.md` §10 の通しプレイが完了しない。
- P0 のクラッシュ、セーブ破損、進行不能が残っている。
- 教材レビュー待ちの問題を「確認済み」と表示している。
- 権利条件が不明な画像・音声を配布物へ含めている。

- 青森の地方ボス撃破から MVP 終了表示までの導線がない。
